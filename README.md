# 键盘热力图（KeyHeat）

Windows 上的键盘使用热力图：全局统计每个按键被按下的次数，用一张会变色的键盘图实时展示。
支持 5 种配列切换、托盘常驻、开机自启，以及**从 GitHub Release 自动更新**。

## 怎么用

**双击 `KeyHeat.exe`** —— 没有控制台窗口，程序在后台常驻，浏览器自动打开面板。

- 面板地址 `http://127.0.0.1:49271/`（端口被占会自动往后找）
- **关闭网页 ≠ 退出**。要真正退出：托盘右键「退出程序」，或面板右下角「退出程序」
- 重复双击不会开第二个：检测到在跑时只把面板再打开一次
- 数据在 `%APPDATA%\KeyHeat\`，每 5 秒自动落盘

## 自动更新

程序启动 6 秒后会静默检查一次 GitHub 上的最新 Release（有本地缓存，6 小时内不重复请求）。

| 时机 | 表现 |
| --- | --- |
| 有新版本 | 面板顶部出现绿色条「发现新版本 vX.Y.Z」，点 **立即更新** |
| 下载中 | 按钮变成进度百分比 |
| 完成 | 自动替换、自动重启，页面稍后自己恢复（约 0.5 秒，端口不变） |
| 失败 | 红条显示原因，可重试；**文件不会被改坏** |

**安全措施**：下载后校验文件大小、SHA-256（GitHub 资产自带的 `digest`）和 PE 头（MZ）；
替换时先把旧 exe 改名、新文件顶上，中途任何一步失败都会回滚；旧文件在下次启动时清理。

**关于 GitHub 限流**：未认证的 API 只有 60 次/小时/IP。所以做了两层保护——本地缓存 6 小时，
外加 `If-None-Match` 条件请求（304 响应不消耗配额）。真被限流时只提示「稍后再试」，不影响使用。

参数：`--no-update`（本次不检查）、`--repo OWNER/NAME`（换仓库）、`--update-api URL`（内网镜像/调试）。

### 发布新版本（以后要做的）

1. 改 `common.py` 里的 `VERSION = "1.2.0"`
2. 双击 `重新打包exe.bat`
3. 在 GitHub 打 tag `v1.2.0`，把 `KeyHeat.exe` 作为 **Release 资产**上传
   - 资产名必须是 `KeyHeat.exe`，或匹配 `KeyHeat*.exe`
   - tag 必须是 `vX.Y.Z`，程序按语义版本比较（1.10.0 > 1.9.9）
4. 老用户下次启动就会看到更新提示

> 仓库地址写在 `common.py` 的 `UPDATE_REPO`，当前是 `zhangjiawang975/KeyHeat`。
> 仓库名不同就改这一行（或用 `--repo` 临时指定）。

## 界面功能

| 功能 | 说明 |
| --- | --- |
| 键盘布局 | 右上角切换：75%（雨75）/ 65% / 60% / 87 TKL / 104 全尺寸，选择会记住 |
| 今日 / 近 7 天 / 全部 | 切换统计范围 |
| 暂停统计 | 临时不计（比如输密码时） |
| 隐藏数字 | 键帽上不显示次数，只看颜色 |
| 导出 CSV | 导出当前范围的「按键 / 键码 / 次数 / 占比」 |
| 开机自启 | 登录 Windows 后自动启动（写 HKCU 的 Run 键，关掉即删除） |
| 检查更新 | 页脚版本号右边 |
| 退出程序 | 保存数据并结束进程 |

快捷键：`Alt + 空格` 暂停 / 继续。

## 托盘图标

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 打开面板 |
| 右键 | 打开面板 / 暂停统计（或继续统计）/ 退出程序 |
| 悬停 | 显示「记录中 · 今日 N 次」 |

> Windows 11 会把新出现的图标默认放进「隐藏的图标」溢出区（任务栏的 `^`）。
> 想常显：展开后把图标拖到任务栏，或去 设置 → 个性化 → 任务栏 → 其他系统托盘图标 里打开。

不想用托盘：`KeyHeat.exe --no-tray`。

## 键盘布局

**只影响显示，不影响统计**——数据按虚拟键码存储，换布局不会丢数据。

| 布局 | 说明 |
| --- | --- |
| 75% · 雨75（82键+旋钮） | 默认。完整 F 区、右侧 Del/Home/PgUp/PgDn 竖列、右下角方向键、右上角旋钮 |
| 65% · 68 键 | 无 F 区，方向键挤在右下，Fn 在底部 |
| 60% · 61 键 | 无 F 区无独立方向键 |
| 87 键 TKL | 保留功能区 + 方向键，去掉小键盘 |
| 104 全尺寸 | 完整布局带小键盘 |

- **旋钮**统计的是音量 +/− 与静音（系统媒体键），悬停有分解说明
- **Fn** 画成虚线框：它在键盘硬件层就被吃掉，Windows 收不到
- 也可用 `#layout=tkl` 这类地址直接指定布局

## 数据在哪

`%APPDATA%\KeyHeat\`：

- `stats.json` —— 累计 + 按天明细（永久保存，不裁剪）
- `update.json` —— 更新检查的缓存与 ETag
- `instance.json` —— 运行时 pid/端口，退出时删除
- `keyheat.log` —— 启动、异常、更新、退出日志（无窗口模式下唯一的排查线索）

## 已知限制

- 管理员权限窗口（任务管理器、UAC 弹窗）里的按键，普通权限下收不到；需要就右键 exe「以管理员身份运行」
- 只识别 ANSI 全尺寸键盘布局；其他配列下多出来的键会显示为未按过，不影响统计
- exe 是 PyInstaller 打包的未签名程序，个别安全软件可能拦一次，需要放行
- 从源码运行（`python keyheat.py`）时不会自动替换文件，更新按钮会提示「源码模式不支持」

## 从源码运行 / 重新打包

```bat
python keyheat.py                 :: 默认 49271 端口并自动开浏览器
python keyheat.py --port 9000     :: 换端口
python keyheat.py --no-open       :: 不自动开浏览器
```

改完代码要出新 exe：双击 `重新打包exe.bat`（会自动装 PyInstaller 后打包）。

只依赖 Python 3.8+ 标准库，源码方式无需安装任何第三方包。
